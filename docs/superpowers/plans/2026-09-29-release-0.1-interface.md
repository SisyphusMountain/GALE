# gpurec 0.1 release interface — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the 4 August 2026 version of gpurec (commit `27cdc472`) into a releasable `v0.1.0` with one Python interface (`load_families`, `fit`, `evaluate`, `sample_reconciliations`, `write_alerax`) and an AleRax-argument command line built on it.

**Architecture:** The Rust preprocessing parses gene trees once into a `FamilyData` object that can build a GPU model for any subset of families. The existing fitting recipes (`fit_global`, `fit_genewise`) take `FamilyData` instead of file paths. A new `gpurec/interface.py` wraps them and returns a `FitResult`; reconciliation samples come from the existing Rust sampler, turned into `ReconciledGeneTree` objects and written in AleRax 1.4.0's file layout by `gpurec/io/alerax_output.py`. The command line (`gpurec/cli/`) only parses AleRax arguments and calls the Python interface.

**Tech Stack:** Python 3.12, PyTorch 2.13 (CUDA 13.0), Triton 3.7, Rust (PyO3 0.22, setuptools-rust), pytest.

**Spec:** `docs/superpowers/specs/2026-09-29-release-0.1-interface-design.md` (read it before starting; section numbers below refer to it).

## Global Constraints

- Work on branch `release/0.1` in `/home/enzo/Documents/git/These/code/gpurec/.worktrees/dev-27cdc47`. Never bring in commits made after 1 September 2026.
- gpurec runs only on a CUDA GPU. No function and no command-line option selects a device. Entry points call `cuda_device()` (Task 10), which raises `RuntimeError` when no GPU is available.
- New code: every function argument is passed explicitly — no default parameter values, no environment variables. Values that cannot be configured are named module constants with a comment saying why.
- Do not change the likelihood kernels or any numerical computation (`gpurec/core/kernels/`, `gpurec/core/inference/`, `gpurec/api/_implicit_grad.py`), except the constant in Task 4 step 5.
- Likelihoods given to users are natural logs (`log_likelihoods`, `per_fam_likelihoods.txt`). The PyTorch module keeps returning negative log-likelihood in bits. Conversion constant: `LN2 = math.log(2.0)`.
- gpurec likelihood values are never compared with AleRax's (author's decision). Comparisons with AleRax outputs are about file layout only.
- Output files follow AleRax 1.4.0 names, headers, columns and row order, except the deliberate differences of spec section 6.5, plus: `_samples.newick` has no branch lengths (gpurec's parsed clades carry none).
- Numbers are written with `format_number` (Task 13): integers as integers (`3`), other values with Python `repr` (full precision).
- Do not write a `LICENSE` file and leave the `license` field of `pyproject.toml` absent.
- Python: `.venv/bin/python` inside the worktree (created in Task 1). Run tests with `.venv/bin/python -m pytest`.
- Commit at the end of every task. Never push, never create a remote tag, without asking the author.

## Review Focus

Inputs the spec implies but that no happy-path test exercises; each line has a test in the named task.

1. A species tree whose internal labels are bootstrap numbers or repeat another label → nodes renamed exactly as AleRax does (Task 9, `test_bootstrap_and_duplicate_internal_labels_are_renamed`).
2. A gene mapped to a species that is not a leaf of the species tree, or a gene absent from its mapping file → the run stops with a message naming the gene and the file (Task 6, two tests).
3. A family with a single gene (no split at all), kept with `--min-covered-species 1` → likelihood is finite and each sample is one leaf clade (Task 11 `test_single_gene_family`, Task 12 `test_single_leaf_tree`).
4. A families file with Windows line endings, `#` comments after values, and spaces around `=` → parsed like AleRax, which strips all whitespace (Task 8, `test_crlf_comments_and_spaces`).
5. An output folder that already contains `reconciliations/` from an earlier run, with sampling requested → the program stops before any computation, leaving existing files untouched (Task 15, `test_existing_reconciliations_folder_is_refused`).

```python
"""Readers for AleRax's input files: families file, gene-to-species mapping, fraction missing.

The rules follow AleRax 1.4.0 (GeneRaxCore ``FamiliesFileParser`` and ``GeneSpeciesMapping``):
all whitespace is removed from every line of a families file, ``#`` starts a comment, lines
before ``[FAMILIES]`` are ignored, and paths are used as written (relative to the current
directory, not to the families file).
"""
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

# Keys AleRax accepts that only concern sequence likelihoods, which gpurec does not compute.
_IGNORED_KEYS = frozenset({"alignment", "likelihoods", "subst_model"})
_TREE_KEYS = frozenset({"gene_tree", "starting_gene_tree"})


@dataclass(frozen=True)
class FamilyEntry:
    name: str
    gene_trees: Path
    mapping: Path | None


def _clean(line: str) -> str:
    return "".join(line.split("#", 1)[0].split())


def read_families_file(path: Path) -> list[FamilyEntry]:
    entries: list[FamilyEntry] = []
    seen: set[str] = set()
    current: dict | None = None
    in_families = False

    def close(record: dict | None) -> None:
        if record is None:
            return
        if record["gene_trees"] is None:
            raise ValueError(f"{path}: family {record['name']!r} has no gene tree (gene_tree=...)")
        entries.append(FamilyEntry(record["name"], record["gene_trees"], record["mapping"]))

    for number, raw in enumerate(Path(path).read_text().splitlines(), start=1):
        line = _clean(raw)
        if not line:
            continue
        if not in_families:
            in_families = line == "[FAMILIES]"
            continue
        if line.startswith("-"):
            close(current)
            name = line[1:]
            if name in seen:
                raise ValueError(f"{path}, line {number}: family {name!r} appears twice")
            seen.add(name)
            current = {"name": name, "gene_trees": None, "mapping": None}
            continue
        if current is None or "=" not in line:
            raise ValueError(f"{path}, line {number}: expected '- name' or 'key = value', got {raw.strip()!r}")
        key, value = line.split("=", 1)
        if key in _TREE_KEYS:
            current["gene_trees"] = Path(value)
        elif key == "mapping":
            current["mapping"] = Path(value)
        elif key not in _IGNORED_KEYS:
            raise ValueError(f"{path}, line {number}: unknown key {key!r}")
    close(current)
    if not in_families:
        raise ValueError(f"{path}: no [FAMILIES] line")
    return entries


def read_mapping_file(path: Path) -> dict[str, str]:
    lines = [line for line in Path(path).read_text().splitlines() if line.strip()]
    mapping: dict[str, str] = {}
    if lines and ":" in lines[0]:
        for line in lines:
            species, genes = line.strip().split(":", 1)
            for gene in genes.split(";"):
                if gene.strip():
                    mapping[gene.strip()] = species.strip()
    else:
        for line in lines:
            fields = line.split()
            if len(fields) < 2:
                raise ValueError(f"{path}: expected 'gene species', got {line.strip()!r}")
            mapping[fields[0]] = fields[1]
    return mapping


def read_fraction_missing_file(path: Path) -> dict[str, float]:
    tokens = Path(path).read_text().split()
    if len(tokens) % 2 != 0:
        raise ValueError(f"{path}: expected pairs 'species fraction'")
    return {tokens[i]: float(tokens[i + 1]) for i in range(0, len(tokens), 2)}
```

```python
"""The species tree with AleRax 1.4.0's node names and file formats.

AleRax (``PLLRootedTree::ensureUniqueLabels``) walks the tree in post-order and renames an
internal node whose label is empty, parses as a number (a bootstrap value), equals a leaf
label, or equals a label already used, to ``Node_<leftmost leaf of left child>_<leftmost leaf
of right child>_<k>`` with ``k`` counting from 0 until the name is unused.
"""
from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class SpeciesTree:
    names: tuple[str, ...]
    lengths: tuple[float, ...]
    child1: tuple[int, ...]
    child2: tuple[int, ...]
    parent: tuple[int, ...]
    root: int
    labels: tuple[str, ...]

    @property
    def leaf_index(self) -> dict[str, int]:
        return {self.labels[i]: i for i in range(len(self.labels)) if self.is_leaf(i)}

    def is_leaf(self, node: int) -> bool:
        return self.child1[node] < 0


def _is_number(label: str) -> bool:
    try:
        float(label)
    except ValueError:
        return False
    return True


def _leftmost_leaf(child1: list[int], node: int) -> int:
    while child1[node] >= 0:
        node = child1[node]
    return node


def _alerax_labels(names: list[str], child1: list[int], child2: list[int]) -> list[str]:
    n = len(names)
    labels = list(names)
    leaf_labels = [names[i] for i in range(n) if child1[i] < 0]
    if len(set(leaf_labels)) != len(leaf_labels):
        raise ValueError("the species tree has two leaves with the same label")
    used = set(leaf_labels)
    for node in range(n):  # gpurec indices are a post-order
        if child1[node] < 0:
            continue
        label = names[node]
        if label == "" or _is_number(label) or label in used:
            prefix = (
                f"Node_{names[_leftmost_leaf(child1, child1[node])]}"
                f"_{names[_leftmost_leaf(child1, child2[node])]}"
            )
            k = 0
            while f"{prefix}_{k}" in used:
                k += 1
            label = f"{prefix}_{k}"
        labels[node] = label
        used.add(label)
    return labels


def species_tree_from_arrays(names, lengths, child1, child2) -> SpeciesTree:
    n = len(names)
    parent = [-1] * n
    for node in range(n):
        for child in (child1[node], child2[node]):
            if child >= 0:
                parent[child] = node
    roots = [node for node in range(n) if parent[node] < 0]
    if len(roots) != 1:
        raise ValueError(f"the species tree must have one root, found {len(roots)}")
    return SpeciesTree(
        names=tuple(names),
        lengths=tuple(float(x) for x in lengths),
        child1=tuple(int(c) for c in child1),
        child2=tuple(int(c) for c in child2),
        parent=tuple(parent),
        root=roots[0],
        labels=tuple(_alerax_labels(list(names), list(child1), list(child2))),
    )


def species_tree_from_preprocess(species_raw: dict) -> SpeciesTree:
    S = int(species_raw["S"])

    def children(key: str) -> list[int]:
        values = species_raw[key]
        values = values.tolist() if hasattr(values, "tolist") else list(values)
        return [int(v) if 0 <= int(v) < S else -1 for v in values]

    return species_tree_from_arrays(
        list(species_raw["names"]), list(species_raw["lengths"]), children("sp_child1"), children("sp_child2")
    )


def _preorder(tree: SpeciesTree) -> list[int]:
    order, stack = [], [tree.root]
    while stack:
        node = stack.pop()
        order.append(node)
        if not tree.is_leaf(node):
            stack.append(tree.child2[node])
            stack.append(tree.child1[node])
    return order


def alerax_node_order(tree: SpeciesTree) -> list[int]:
    """Leaves in left-to-right order, then internal non-root nodes in pre-order, then the root."""
    preorder = _preorder(tree)
    leaves = [node for node in preorder if tree.is_leaf(node)]
    internals = [node for node in preorder if not tree.is_leaf(node) and node != tree.root]
    return leaves + internals + [tree.root]


def species_tree_newick(tree: SpeciesTree, lengths: list[float]) -> str:
    """AleRax's writer: ``%s:%f`` at leaves, ``(%s,%s)%s:%f`` inside, root length included."""

    def text(node: int) -> str:
        if tree.is_leaf(node):
            return f"{tree.labels[node]}:{lengths[node]:.6f}"
        return f"({text(tree.child1[node])},{text(tree.child2[node])}){tree.labels[node]}:{lengths[node]:.6f}"

    return text(tree.root) + ";\n"
```

```python
@dataclass(frozen=True)
class FamilyData:
```

```python
    def build_model(

def _family_entries(families) -> list[FamilyEntry]:
    if isinstance(families, (list, tuple)):
        entries = [FamilyEntry(Path(p).stem, Path(p), None) for p in families]
    else:
        path = Path(families)
        if path.is_dir():
            entries = [
                FamilyEntry(p.stem, p, None) for p in sorted(path.iterdir()) if p.suffix in _TREE_SUFFIXES
            ]
        else:
            entries = read_families_file(path)
    names = [entry.name for entry in entries]
    duplicates = sorted({name for name in names if names.count(name) > 1})
    if duplicates:
        raise ValueError(f"two families have the same name: {', '.join(duplicates)}")
    return entries


def _unreadable_file_problem(entry: FamilyEntry) -> str | None:
    for kind, path in (("gene tree", entry.gene_trees), ("mapping", entry.mapping)):
        if path is None:
            continue
        if not path.is_file():
            return f"cannot open the {kind} file {path}"
        if path.stat().st_size == 0:
            return f"the {kind} file {path} is empty"
    return None


def _keep(order, keep, reason, entries, dropped) -> list[int]:
    kept = []
    for i in order:
        if keep(i):
            kept.append(i)
        else:
            message = reason(i)
            logger.info("Excluding family %s: %s", entries[i].name, message)
            dropped.append((entries[i].name, message))
    return kept


def _fraction_missing(path: Path, species: SpeciesTree) -> dict[str, float]:
    values = read_fraction_missing_file(path)
    leaves = set(species.leaf_index)
    unknown = sorted(set(values) - leaves)
    missing = sorted(leaves - set(values))
    if unknown:
        raise ValueError(f"{path}: not leaves of the species tree: {', '.join(unknown)}")
    if missing:
        raise ValueError(f"{path} does not cover species: {', '.join(missing)}")
    bad = sorted(name for name, value in values.items() if not 0.0 <= value < 1.0)
    if bad:
        raise ValueError(f"{path}: fractions must be in [0, 1): {', '.join(bad)}")
    return values


def load_families(
    families,
    species_tree: Path,
    min_covered_species: int,
    trim_ratio: float,
    max_clade_split_ratio: float | None,
    fraction_missing: Path | None,
    skip_family_filtering: bool,
) -> FamilyData:
    """Read gene families and apply AleRax 1.4.0's family filtering, in AleRax's order."""
    species_path = Path(species_tree)
    entries = _family_entries(families)
    dropped: list[tuple[str, str]] = []
    if not skip_family_filtering:
        entries = [entries[i] for i in _keep(
            range(len(entries)),
            lambda i: _unreadable_file_problem(entries[i]) is None,
            lambda i: _unreadable_file_problem(entries[i]),
            entries,
            dropped,
        )]
    if not entries:
        raise ValueError("no gene family to process")
    mappings = [None if entry.mapping is None else read_mapping_file(entry.mapping) for entry in entries]
    raw = preprocess_dataset(
        str(species_path),
        [str(entry.gene_trees) for entry in entries],
        gene_to_species=mappings,
        family_chunk_size=None,
        clade_budget=None,
        batch_packing="sequential",
        max_wave_size=DEFAULT_MAX_WAVE_SIZE,
        family_group_assignments=None,
        accumulator_dtype=torch.float64,
    )
    species = species_tree_from_preprocess(raw["species"])
    payloads = raw["families"]
    covered = [
        frozenset(mapping.values()) if mapping is not None
        else frozenset(species.names[column] for column in payload["leaf_col_index"])
        for mapping, payload in zip(mappings, payloads)
    ]
    order = _keep(
        range(len(entries)),
        lambda i: len(covered[i]) >= min_covered_species,
        lambda i: f"covers {len(covered[i])} species, fewer than {min_covered_species}",
        entries,
        dropped,
    )
    if trim_ratio > 0.0:
        by_size = sorted(order, key=lambda i: int(payloads[i]["C"]))
        n_keep = math.floor(len(by_size) * (1.0 - trim_ratio))
        for i in by_size[n_keep:]:
            logger.info("Excluding family %s: trimmed by --trim-ratio %s", entries[i].name, trim_ratio)
            dropped.append((entries[i].name, f"trimmed by --trim-ratio {trim_ratio}"))
        order = by_size[:n_keep]
    if max_clade_split_ratio is not None:
        order = _keep(
            order,
            lambda i: max_clade_split_ratio * (2 * len(payloads[i]["leaf_row_index"]) - 3) >= int(payloads[i]["C"]),
            lambda i: f"has more clades than {max_clade_split_ratio} x (2 x genes - 3)",
            entries,
            dropped,
        )
    if not order:
        raise ValueError("no gene family is left after filtering")
    logger.info("Remaining families: %d", len(order))
    return FamilyData(
        species_tree_path=species_path,
        species=species,
        species_raw=raw["species"],
        families=tuple(payloads[i] for i in order),
        names=tuple(entries[i].name for i in order),
        covered_species=tuple(covered[i] for i in order),
        dropped=tuple(dropped),
        fraction_missing=None if fraction_missing is None else _fraction_missing(Path(fraction_missing), species),
    )
```

```python
"""The Python interface: fit DTL rates, evaluate likelihoods at fixed rates."""
from __future__ import annotations

import math
import time
from dataclasses import dataclass, replace

import torch

from gpurec.api.model import DEFAULT_CLADE_BUDGET, GeneReconModel
from gpurec.config import GpurecConfig
from gpurec.data import FamilyData
from gpurec.fit.genewise_fit import fit_genewise
from gpurec.fit.global_fit import fit_global

LN2 = math.log(2.0)
PARAMETRIZATIONS = ("global", "per-family")


@dataclass(frozen=True)
class FitResult:
    data: FamilyData
    parametrization: str
    log2_rates: torch.Tensor
    log_likelihoods: dict[str, float]
    model: GeneReconModel
    history: dict | None
    wall_seconds: float

    @property
    def rates(self) -> dict:
        values = torch.exp2(self.log2_rates.double())
        if self.parametrization == "global":
            return {"D": float(values[0, 0]), "L": float(values[0, 1]), "T": float(values[0, 2])}
        return {
            name: {"D": float(row[0]), "L": float(row[1]), "T": float(row[2])}
            for name, row in zip(self.data.names, values)
        }


def _log2_rates(rates) -> torch.Tensor:
    values = [float(value) for value in rates]
    if len(values) != 3 or not all(value > 0.0 and math.isfinite(value) for value in values):
        raise ValueError(f"rates must be three positive numbers (D, L, T), got {tuple(rates)!r}")
    return torch.log2(torch.tensor(values, dtype=torch.float64))


def _check_parametrization(parametrization: str) -> None:
    if parametrization not in PARAMETRIZATIONS:
        raise ValueError(f"parametrization must be one of {PARAMETRIZATIONS}, got {parametrization!r}")


def _result(data, parametrization, log2_rates, config, history, wall_seconds) -> FitResult:
    model = data.build_model(
        list(range(data.n_families)), "genewise", replace(config.solver, warm_adjoint=False), config,
        DEFAULT_CLADE_BUDGET,
    )
    with torch.no_grad():
        model.theta.copy_(log2_rates.to(device=model.theta.device, dtype=model.theta.dtype))
        nll_bits = model.genewise_loss_vector().double().cpu()
    log_likelihoods = {name: -float(bits) * LN2 for name, bits in zip(data.names, nll_bits)}
    return FitResult(data, parametrization, log2_rates.double().cpu(), log_likelihoods, model, history, wall_seconds)


def evaluate(data: FamilyData, parametrization: str, rates, config: GpurecConfig) -> FitResult:
    _check_parametrization(parametrization)
    start = time.perf_counter()
    log2_rates = _log2_rates(rates).reshape(1, 3).expand(data.n_families, 3).clone()
    result = _result(data, parametrization, log2_rates, config, None, 0.0)
    return replace(result, wall_seconds=time.perf_counter() - start)


def fit(data: FamilyData, parametrization: str, start_rates, config: GpurecConfig) -> FitResult:
    _check_parametrization(parametrization)
    start = _log2_rates(start_rates)
    t0 = time.perf_counter()
    if parametrization == "global":
        res = fit_global(data, start_log2_rates=start, config=config, verbose=True)
        log2_rates = res["theta"].double().reshape(1, 3).expand(data.n_families, 3).clone()
        history = {"n_steps": res["n_steps"]}
    else:
        res = fit_genewise(
            data,
            start_log2_rates=start.reshape(1, 3).expand(data.n_families, 3).clone(),
            config=config,
            certify=False,
            verbose=True,
        )
        log2_rates = res["theta"].detach().double().cpu()
        history = res["history"]
    return _result(data, parametrization, log2_rates, config, history, time.perf_counter() - t0)
```

```python
"""A sampled reconciliation as a gene tree whose nodes carry AleRax-style events.

gpurec's sampler returns nodes ``(event, species, [left, right], clade)``. AleRax records, per
gene node, zero or more SL/TL events followed by one S, D, T or Leaf event; dying copies
(duplication-loss, transfer whose transferred copy is lost) are not recorded, and gpurec's sampler
does not emit them either. For a transfer the donor-side child comes first, as in AleRax.
"""
from __future__ import annotations

import contextlib
import sys
from dataclasses import dataclass

EVENT_KINDS = ("S", "SL", "D", "T", "TL", "Leaf")


@dataclass(frozen=True)
class Event:
    kind: str
    species: int
    dest: int
    lost: int
    previous: str


@dataclass(frozen=True)
class GeneNode:
    events: tuple[Event, ...]
    gene: str | None
    left: "GeneNode | None"
    right: "GeneNode | None"


@contextlib.contextmanager
def deep_recursion(depth: int):
    """Raise Python's recursion limit (1000 by default) to walk gene trees deeper than that."""
    previous = sys.getrecursionlimit()
    sys.setrecursionlimit(max(previous, depth + 1000))
    try:
        yield
    finally:
        sys.setrecursionlimit(previous)


@dataclass(frozen=True)
class ReconciledGeneTree:
    root: GeneNode
    n_nodes: int

    def events(self) -> list[Event]:
        out, stack = [], [self.root]
        while stack:
            node = stack.pop()
            out.extend(node.events)
            if node.left is not None:
                stack.append(node.right)
                stack.append(node.left)
        return out

    def genes(self) -> list[str]:
        out, stack = [], [self.root]
        while stack:
            node = stack.pop()
            if node.left is None:
                out.append(node.gene)
            else:
                stack.append(node.right)
                stack.append(node.left)
        return out

    @property
    def origin(self) -> int:
        return self.root.events[0].species


def tree_from_sampler_nodes(nodes: list, clade_to_gene: dict[int, str]) -> ReconciledGeneTree:
    def build(index: int, previous: str) -> GeneNode:
        events = []
        while True:
            kind, species, (a, b), clade = nodes[index]
            if kind == "speciation" and a >= 0 and nodes[b][0] == "loss":
                events.append(Event("SL", species, nodes[a][1], nodes[b][1], previous))
                previous, index = "SL", a
                continue
            if kind == "transfer" and a >= 0 and nodes[a][0] == "loss":
                events.append(Event("TL", species, nodes[b][1], -1, previous))
                previous, index = "TL", b
                continue
            if kind == "leaf":
                events.append(Event("Leaf", species, -1, -1, previous))
                return GeneNode(tuple(events), clade_to_gene[clade], None, None)
            if kind == "speciation":
                event, left, right, left_previous, right_previous = Event("S", species, -1, -1, previous), a, b, "S", "S"
            elif kind == "duplication":
                event, left, right, left_previous, right_previous = Event("D", species, -1, -1, previous), a, b, "D", "D"
            elif kind == "transfer":
                donor, recipient = (a, b) if nodes[a][1] == species else (b, a)
                event = Event("T", species, nodes[recipient][1], -1, previous)
                left, right, left_previous, right_previous = donor, recipient, previous, "T"
            else:
                raise ValueError(f"unexpected sampled event {kind!r}")
            events.append(event)
            return GeneNode(tuple(events), None, build(left, left_previous), build(right, right_previous))

    with deep_recursion(4 * len(nodes)):
        root = build(0, "S")
    return ReconciledGeneTree(root, len(nodes))
```

```python
"""Draw reconciliation samples for every family, one forward solve per batch."""
from __future__ import annotations

import hashlib

import torch

from gpurec.core.backtracking.input import _load_native_module, batch_forward, family_sampler_arguments
from gpurec.reconciliation.tree import ReconciledGeneTree, tree_from_sampler_nodes


def sample_seed(seed: int, family: str, index: int) -> int:
    """A 64-bit seed for sample ``index`` of ``family``: independent of batching and family order."""
    digest = hashlib.sha256(f"{seed}\0{family}\0{index}".encode()).digest()
    return int.from_bytes(digest[:8], "little")


def sample_family_reconciliations(model, data, n: int, seed: int) -> dict[str, list[ReconciledGeneTree]]:
    if n < 0:
        raise ValueError(f"the number of samples must be non-negative, got {n}")
    native = _load_native_module()
    samples: dict[str, list[ReconciledGeneTree]] = {}
    with torch.no_grad():
        for static in model.batch_statics:
            forward = batch_forward(model, static)
            for local, family_index in enumerate(static.family_indices):
                name = data.names[family_index]
                family = model.families[family_index]
                clade_to_gene = {
                    int(clade): gene for clade, gene in zip(family["leaf_row_index"], family["leaf_gene_names"])
                }
                seeds = [sample_seed(seed, name, i) for i in range(n)]
                arguments = family_sampler_arguments(model, static, forward, local)
                samples[name] = [
                    tree_from_sampler_nodes(nodes, clade_to_gene)
                    for nodes in native.sample_reconciliations_many(*arguments, seeds)
                ]
    return {name: samples[name] for name in data.names}
```

```python
"""Per-sample files of AleRax 1.4.0 (GeneRaxCore ``Scenario`` and ``ReconciliationWriter``)."""
from __future__ import annotations

from gpurec.io.species_tree import SpeciesTree
from gpurec.io.text import format_number
from gpurec.reconciliation.tree import GeneNode, ReconciledGeneTree, deep_recursion

SPECIES_COUNT_HEADER = (
    "species_label, speciations, duplications, losses, transfers, presence, origination, "
    "copies, singletons, transfers_to\n"
)
_EVENT_COUNT_NAMES = ("S", "SL", "D", "DL", "T", "TL", "L", "Leaf")
_XML_TAGS = {
    "Leaf": "leaf", "S": "speciation", "SL": "speciation", "D": "duplication",
    "T": "branchingOut", "TL": "branchingOut", "L": "loss",
}
_XML_HEADER = (
    "<recPhylo \n"
    '\txmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"\n'
    '\txsi:schemaLocation="http://www.recg.org ./recGeneTreeXML.xsd"\n'
    '\txmlns="http://www.recg.org">\n'
)


def _species_clades(species: SpeciesTree, node: int, indent: str, out: list[str]) -> None:
    out.append(f"{indent}<clade>\n")
    out.append(f"{indent}\t<name>{species.labels[node]}</name>\n")
    if not species.is_leaf(node):
        _species_clades(species, species.child1[node], indent + "\t", out)
        _species_clades(species, species.child2[node], indent + "\t", out)
    out.append(f"{indent}</clade>\n")


def _events_rec(out: list[str], indent: str, kind: str, location: str, transfer_back: str | None) -> None:
    out.append(f"{indent}<eventsRec>\n")
    if transfer_back is not None:
        out.append(f'{indent}\t<transferBack destinationSpecies="{transfer_back}"/>\n')
    out.append(f'{indent}\t<{_XML_TAGS[kind]} speciesLocation="{location}"/>\n')
    out.append(f"{indent}</eventsRec>\n")


def _transfer_back(previous, on_recipient_side: bool, species: SpeciesTree) -> str | None:
    if previous is not None and (previous.kind == "TL" or (previous.kind == "T" and on_recipient_side)):
        return species.labels[previous.dest]
    return None


def _gene_clades(node: GeneNode, previous, on_recipient_side: bool, indent: str,
                 species: SpeciesTree, out: list[str]) -> None:
    *chain, last = node.events
    for event in chain:
        out.append(f"{indent}<clade>\n")
        indent += "\t"
        out.append(f"{indent}<name>NULL</name>\n")
        _events_rec(out, indent, event.kind, species.labels[event.species],
                    _transfer_back(previous, on_recipient_side, species))
        previous, on_recipient_side = event, False
        loss_species = event.lost if event.kind == "SL" else event.species
        out.append(f"{indent}<clade>\n")
        out.append(f"{indent}\t<name>loss</name>\n")
        _events_rec(out, indent + "\t", "L", species.labels[loss_species], None)
        out.append(f"{indent}</clade>\n")
    out.append(f"{indent}<clade>\n")
    out.append(f"{indent}\t<name>{node.gene if node.gene is not None else 'NULL'}</name>\n")
    _events_rec(out, indent + "\t", last.kind, species.labels[last.species],
                _transfer_back(previous, on_recipient_side, species))
    if node.left is not None:
        _gene_clades(node.left, last, False, indent + "\t", species, out)
        _gene_clades(node.right, last, True, indent + "\t", species, out)
    out.append(f"{indent}</clade>\n")
    for _ in chain:
        indent = indent[:-1]
        out.append(f"{indent}</clade>\n")


def recphyloxml_text(tree: ReconciledGeneTree, species: SpeciesTree) -> str:
    out = [_XML_HEADER, "<spTree>\n<phylogeny>\n"]
    _species_clades(species, species.root, "", out)
    out.append('</phylogeny>\n</spTree>\n<recGeneTree>\n<phylogeny rooted="true">\n')
    with deep_recursion(4 * tree.n_nodes):
        _gene_clades(tree.root, None, False, "", species, out)
    out.append("</phylogeny>\n</recGeneTree>\n</recPhylo>\n")
    return "".join(out)


def samples_newick_line(tree: ReconciledGeneTree) -> str:
    """One line of ``<family>_samples.newick``; gpurec has no branch lengths to write."""

    def text(node: GeneNode) -> str:
        if node.left is None:
            return node.gene
        return f"({text(node.left)},{text(node.right)}){node.events[-1].kind}"

    with deep_recursion(4 * tree.n_nodes):
        return text(tree.root) + ";\n"


def event_counts_text(tree: ReconciledGeneTree) -> str:
    counts = {name: 0 for name in _EVENT_COUNT_NAMES}
    for event in tree.events():
        counts[event.kind] += 1
    return "".join(f"{name}:{counts[name]}\n" for name in _EVENT_COUNT_NAMES)


def species_event_counts(tree: ReconciledGeneTree, species: SpeciesTree) -> list[list[float]]:
    """Columns: speciations, duplications, losses, transfers, presence, origination, copies,
    singletons, transfers_to (AleRax ``Scenario::saveSpeciesEventCounts``)."""
    counts = [[0.0] * 9 for _ in species.labels]
    for event in tree.events():
        row = counts[event.species]
        if event.kind in ("S", "SL", "Leaf"):
            row[0] += 1
            row[4] = 1
            row[6] += 1
            if event.previous in ("S", "SL"):
                row[7] += 1
            if event.kind == "SL":
                counts[event.lost][2] += 1
        elif event.kind == "D":
            row[1] += 1
        elif event.kind == "T":
            row[3] += 1
            counts[event.dest][8] += 1
        elif event.kind == "TL":
            row[2] += 1
            row[3] += 1
            counts[event.dest][8] += 1
    counts[tree.origin][5] = 1
    return counts


def species_event_counts_text(counts: list[list[float]], species: SpeciesTree) -> str:
    rows = [SPECIES_COUNT_HEADER]
    # AleRax sorts species labels byte-wise in its summary files; gpurec uses that order everywhere.
    for label, node in sorted(((label, node) for node, label in enumerate(species.labels)), key=lambda item: item[0].encode()):
        values = counts[node]
        if any(value != 0 for value in values):
            rows.append(label + "".join(f", {format_number(value)}" for value in values) + "\n")
    return "".join(rows)


def transfer_pairs(tree: ReconciledGeneTree) -> list[tuple[int, int]]:
    return [(event.species, event.dest) for event in tree.events() if event.kind in ("T", "TL")]


def transfers_text(tree: ReconciledGeneTree, species: SpeciesTree) -> str:
    return "".join(f"{species.labels[src]} {species.labels[dst]} 1\n" for src, dst in transfer_pairs(tree))
```

```python
"""Summary files of AleRax 1.4.0: per-family means, whole-dataset totals, transfer origins."""
from __future__ import annotations

from gpurec.io.species_tree import SpeciesTree
from gpurec.io.text import format_number
from gpurec.reconciliation.files import transfer_pairs
from gpurec.reconciliation.tree import ReconciledGeneTree


def mean_species_event_counts(per_sample: list[list[list[float]]], n_species: int) -> list[list[float]]:
    mean = [[0.0] * 9 for _ in range(n_species)]
    for counts in per_sample:
        for node in range(n_species):
            for column in range(9):
                mean[node][column] += counts[node][column]
    return [[value / len(per_sample) for value in row] for row in mean]


def mean_transfers(trees: list[ReconciledGeneTree]) -> dict[tuple[int, int], float]:
    totals: dict[tuple[int, int], float] = {}
    for tree in trees:
        for pair in transfer_pairs(tree):
            totals[pair] = totals.get(pair, 0.0) + 1.0
    return {pair: count / len(trees) for pair, count in totals.items()}


def _rank(species: SpeciesTree) -> dict[int, int]:
    """AleRax orders species by their label sorted byte-wise."""
    order = sorted(range(len(species.labels)), key=lambda node: species.labels[node].encode())
    return {node: position for position, node in enumerate(order)}


def transfers_table_text(values: dict[tuple[int, int], float], species: SpeciesTree) -> str:
    rank = _rank(species)
    rows = sorted(
        ((count, rank[src], rank[dst], src, dst) for (src, dst), count in values.items() if count > 0),
        reverse=True,
    )
    return "".join(
        f"{species.labels[src]} {species.labels[dst]} {format_number(count)}\n"
        for count, _, _, src, dst in rows
    )


def origin_texts(samples: dict[str, list[ReconciledGeneTree]], species: SpeciesTree, n_samples: int) -> dict[int, str]:
    """``origins/<label>.txt``: how often a lineage in each species arrived vertically or by transfer."""
    n = len(species.labels)
    vertical = [0.0] * n
    by_transfer = [[0.0] * n for _ in range(n)]  # [source][destination]
    for trees in samples.values():
        for tree in trees:
            for event in tree.events():
                if event.kind in ("T", "TL"):
                    by_transfer[event.species][event.dest] += 1
                elif event.kind == "S":
                    vertical[species.child1[event.species]] += 1
                    vertical[species.child2[event.species]] += 1
                elif event.kind == "SL":
                    vertical[event.dest] += 1
                    vertical[event.lost] += 1
    rank = _rank(species)
    texts = {}
    for node in range(n):
        lines = [f"vertical: {format_number(vertical[node] / n_samples)}\n"]
        sources = sorted(
            ((by_transfer[src][node], rank[src], src) for src in range(n) if by_transfer[src][node] > 0),
            reverse=True,
        )
        lines += [f"{species.labels[src]}, {format_number(count / n_samples)}\n" for count, _, src in sources]
        texts[node] = "".join(lines)
    return texts
```

```python
"""Write results in AleRax 1.4.0's output layout (see the spec, section 6)."""
from __future__ import annotations

from pathlib import Path

import torch

from gpurec.io.species_tree import alerax_node_order, species_tree_newick
from gpurec.io.text import format_number
from gpurec.reconciliation.files import (
    event_counts_text,
    recphyloxml_text,
    samples_newick_line,
    species_event_counts,
    species_event_counts_text,
    transfers_text,
)
from gpurec.reconciliation.summaries import (
    mean_species_event_counts,
    mean_transfers,
    origin_texts,
    transfers_table_text,
)


def _write(path: Path, text: str) -> None:
    path.write_text(text)


def _coverage_text(data) -> str:
    rows = []
    for label in data.species.leaf_index:
        covering = sum(1 for covered in data.covered_species if label in covered)
        rows.append((covering / data.n_families, label))
    return "".join(f"{label} {format_number(fraction)}\n" for fraction, label in sorted(rows))


def _write_reconciliations(samples, species, folder: Path) -> None:
    all_dir, summaries = folder / "all", folder / "summaries"
    for directory in (all_dir, summaries, folder / "origins"):
        directory.mkdir(parents=True, exist_ok=True)
    n_species = len(species.labels)
    total_counts = [[0.0] * 9 for _ in range(n_species)]
    total_transfers: dict[tuple[int, int], float] = {}
    n_samples = 0
    for name, trees in samples.items():
        n_samples = len(trees)
        per_sample = []
        for i, tree in enumerate(trees):
            counts = species_event_counts(tree, species)
            per_sample.append(counts)
            _write(all_dir / f"{name}_sample_{i}.xml", recphyloxml_text(tree, species))
            _write(all_dir / f"{name}_eventCounts_{i}.txt", event_counts_text(tree))
            _write(all_dir / f"{name}_speciesEventCounts_{i}.txt", species_event_counts_text(counts, species))
            _write(all_dir / f"{name}_transfers_{i}.txt", transfers_text(tree, species))
        _write(all_dir / f"{name}_samples.newick", "".join(samples_newick_line(tree) for tree in trees))
        mean_counts = mean_species_event_counts(per_sample, n_species)
        _write(summaries / f"{name}_meanSpeciesEventCounts.txt", species_event_counts_text(mean_counts, species))
        family_transfers = mean_transfers(trees)
        _write(summaries / f"{name}_meanTransfers.txt", transfers_table_text(family_transfers, species))
        for node in range(n_species):
            for column in range(9):
                total_counts[node][column] += mean_counts[node][column]
        for pair, value in family_transfers.items():
            total_transfers[pair] = total_transfers.get(pair, 0.0) + value
    _write(folder / "totalSpeciesEventCounts.txt", species_event_counts_text(total_counts, species))
    _write(folder / "totalTransfers.txt", transfers_table_text(total_transfers, species))
    for node, text in origin_texts(samples, species, n_samples).items():
        _write(folder / "origins" / f"{species.labels[node]}.txt", text)


def write_alerax(result, samples, prefix: Path) -> None:
    prefix = Path(prefix)
    prefix.mkdir(parents=True, exist_ok=True)
    data, species = result.data, result.data.species
    ordered = sorted((value, name) for name, value in result.log_likelihoods.items())
    _write(prefix / "per_fam_likelihoods.txt", "".join(f"{name} {format_number(value)}\n" for value, name in ordered))

    rates = torch.exp2(result.log2_rates.double()).tolist()
    parameters = prefix / "model_parameters"
    parameters.mkdir(exist_ok=True)
    if result.parametrization == "global":
        d, l, t = (format_number(value) for value in rates[0])
        rows = "".join(f"{species.labels[node]} {d} {l} {t}\n" for node in alerax_node_order(species))
        _write(parameters / "model_parameters.txt", "node D L T\n" + rows)
    else:
        for name, row in zip(data.names, rates):
            _write(parameters / f"{name}_rates.txt", "D L T\n" + " ".join(format_number(v) for v in row) + "\n")

    trees = prefix / "species_trees"
    trees.mkdir(exist_ok=True)
    _write(trees / "starting_species_tree.newick",
           species_tree_newick(species, [length if length > 0 else 1.0 for length in species.lengths]))
    _write(trees / "inferred_species_tree.newick", species_tree_newick(species, [1.0] * len(species.labels)))
    _write(prefix / "perSpeciesCoverage.txt", _coverage_text(data))
    if samples is not None:
        _write_reconciliations(samples, species, prefix / "reconciliations")
```

```python
"""AleRax 1.4.0's command-line arguments, restricted to what gpurec implements."""
from __future__ import annotations

import argparse
from dataclasses import dataclass
from pathlib import Path

# AleRax 1.4.0 defaults (src/ale/AleArguments.cpp); they are AleRax's documented values,
# not gpurec settings, which is why they live here and not in the config file.
ALERAX_DEFAULT_PREFIX = "alerax_output"
ALERAX_DEFAULT_RATE = 0.1
ALERAX_DEFAULT_SAMPLES = 100
ALERAX_DEFAULT_SEED = 123
ALERAX_DEFAULT_MIN_COVERED_SPECIES = 4
ALERAX_DEFAULT_TRIM_RATIO = 0.0
ALERAX_DEFAULT_MAX_CLADE_SPLIT_RATIO = -1.0
ALERAX_DEFAULT_PARAMETRIZATION = "GLOBAL"
# AleRax options that describe a model choice; gpurec implements exactly one value of each.
FIXED_VALUE_OPTIONS = {
    "--rec-model": "UndatedDTL",
    "--transfer-constraint": "PARENTS",
    "--gene-tree-rooting": "UNIFORM",
    "--origination": "UNIFORM",
    "--species-tree-search": "SKIP",
}
PARAMETRIZATIONS = {"GLOBAL": "global", "PER-FAMILY": "per-family"}
NAMED_SPECIES_TREES = ("Random", "MiniNJ", "NJst", "WMiniNJ", "Ustar", "Cherry", "CherryPro")


class UsageError(Exception):
    """The command line is not valid; the message lists every problem found."""


@dataclass(frozen=True)
class RunArguments:
    families: Path
    species_tree: Path
    prefix: Path
    parametrization: str
    start_rates: tuple[float, float, float]
    fix_rates: bool
    samples: int
    seed: int
    fraction_missing_file: Path | None
    min_covered_species: int
    trim_ratio: float
    max_clade_split_ratio: float | None
    skip_family_filtering: bool
    verbose_opt: bool
    precision: str | None
    config: Path | None


def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="gpurec",
        description="Undated DTL reconciliation on a GPU, with AleRax's arguments and output files.",
        allow_abbrev=False,
    )
    parser.add_argument("-f", "--families", help="AleRax families file")
    parser.add_argument("-s", "--species-tree", help="rooted species tree (Newick file)")
    parser.add_argument("-p", "--prefix", default=ALERAX_DEFAULT_PREFIX, help="output folder")
    parser.add_argument("--model-parametrization", default=ALERAX_DEFAULT_PARAMETRIZATION,
                        help="GLOBAL or PER-FAMILY")
    parser.add_argument("--d", type=float, default=ALERAX_DEFAULT_RATE, help="duplication rate (start value)")
    parser.add_argument("--l", type=float, default=ALERAX_DEFAULT_RATE, help="loss rate (start value)")
    parser.add_argument("--t", type=float, default=ALERAX_DEFAULT_RATE, help="transfer rate (start value)")
    parser.add_argument("--fix-rates", action="store_true", help="evaluate at --d --l --t without fitting")
    parser.add_argument("-g", "--gene-tree-samples", type=int, default=ALERAX_DEFAULT_SAMPLES,
                        help="reconciliations sampled per family (0: none)")
    parser.add_argument("--seed", type=int, default=ALERAX_DEFAULT_SEED)
    parser.add_argument("--fraction-missing-file", help="lines 'species fraction'")
    parser.add_argument("--min-covered-species", type=int, default=ALERAX_DEFAULT_MIN_COVERED_SPECIES)
    parser.add_argument("--trim-ratio", type=float, default=ALERAX_DEFAULT_TRIM_RATIO)
    parser.add_argument("--max-clade-split-ratio", type=float, default=ALERAX_DEFAULT_MAX_CLADE_SPLIT_RATIO)
    parser.add_argument("--skip-family-filtering", action="store_true")
    parser.add_argument("--verbose-opt", action="store_true", help="log every optimizer step")
    for option, value in FIXED_VALUE_OPTIONS.items():
        parser.add_argument(option, default=value, help=f"only {value} is supported")
    parser.add_argument("--precision", choices=("float32", "float64"),
                        help="gpurec only: floating-point precision (default: from the config file)")
    parser.add_argument("--config", help="gpurec only: TOML file with solver, memory and precision settings")
    return parser


def parse_arguments(argv: list[str]) -> RunArguments:
    args, unknown = _parser().parse_known_args(argv)
    problems = []
    unsupported = [token for token in unknown if token.startswith("-")]
    if unsupported:
        problems.append("unsupported AleRax option(s): " + ", ".join(unsupported))
    if args.families is None:
        problems.append("missing -f/--families")
    if args.species_tree is None:
        problems.append("missing -s/--species-tree")
    elif args.species_tree in NAMED_SPECIES_TREES:
        problems.append(f"-s {args.species_tree}: gpurec needs a species tree file")
    for option, value in FIXED_VALUE_OPTIONS.items():
        given = getattr(args, option[2:].replace("-", "_"))
        if given != value:
            problems.append(f"{option} {given} is not supported (only {value})")
    if args.model_parametrization not in PARAMETRIZATIONS:
        problems.append(
            f"--model-parametrization {args.model_parametrization} is not supported (only GLOBAL or PER-FAMILY)"
        )
    for option in ("d", "l", "t"):
        if not getattr(args, option) > 0:
            problems.append(f"--{option} must be positive")
    if args.gene_tree_samples < 0:
        problems.append("-g/--gene-tree-samples must be 0 or more")
    if problems:
        raise UsageError("; ".join(problems))
    return RunArguments(
        families=Path(args.families),
        species_tree=Path(args.species_tree),
        prefix=Path(args.prefix),
        parametrization=PARAMETRIZATIONS[args.model_parametrization],
        start_rates=(args.d, args.l, args.t),
        fix_rates=args.fix_rates,
        samples=args.gene_tree_samples,
        seed=args.seed,
        fraction_missing_file=None if args.fraction_missing_file is None else Path(args.fraction_missing_file),
        min_covered_species=args.min_covered_species,
        trim_ratio=args.trim_ratio,
        max_clade_split_ratio=args.max_clade_split_ratio if args.max_clade_split_ratio > 0 else None,
        skip_family_filtering=args.skip_family_filtering,
        verbose_opt=args.verbose_opt,
        precision=args.precision,
        config=None if args.config is None else Path(args.config),
    )
```

```python
"""``gpurec``: the AleRax-compatible command line."""
from __future__ import annotations

import logging
import shlex
import sys
import time
from importlib.metadata import version

from gpurec.cli.arguments import UsageError, parse_arguments

logger = logging.getLogger("gpurec")


def _configure_logging(log_path, verbose: bool) -> list[logging.Handler]:
    formatter = logging.Formatter("[%(asctime)s] %(message)s", datefmt="%H:%M:%S")
    handlers = [logging.StreamHandler(sys.stderr), logging.FileHandler(log_path, mode="a")]
    for handler in handlers:
        handler.setFormatter(formatter)
        logger.addHandler(handler)
    logger.setLevel(logging.DEBUG if verbose else logging.INFO)
    return handlers


def main(argv: list[str]) -> int:
    try:
        args = parse_arguments(argv)
    except UsageError as error:
        sys.stderr.write(f"gpurec: {error}\n")
        return 2
    if args.samples > 0 and (args.prefix / "reconciliations").exists():
        sys.stderr.write(
            f"gpurec: {args.prefix / 'reconciliations'} already exists; choose another -p/--prefix "
            "or remove it (gpurec does not overwrite earlier samples)\n"
        )
        return 2
    args.prefix.mkdir(parents=True, exist_ok=True)
    handlers = _configure_logging(args.prefix / "gpurec.log", args.verbose_opt)
    started = time.perf_counter()
    try:
        import torch

        from gpurec import cuda_device, evaluate, fit, load_families, load_fit_config, write_alerax

        cuda_device()
        logger.info("gpurec %s", version("gpurec"))
        logger.info("command: %s", shlex.join(["gpurec", *argv]))
        logger.info("GPU: %s", torch.cuda.get_device_name(0))
        config = load_fit_config(args.config)
        if args.precision is not None:
            config.precision.model_dtype = args.precision
        config.validate()
        data = load_families(
            families=args.families,
            species_tree=args.species_tree,
            min_covered_species=args.min_covered_species,
            trim_ratio=args.trim_ratio,
            max_clade_split_ratio=args.max_clade_split_ratio,
            fraction_missing=args.fraction_missing_file,
            skip_family_filtering=args.skip_family_filtering,
        )
        if args.fix_rates:
            result = evaluate(data, args.parametrization, args.start_rates, config)
        else:
            result = fit(data, args.parametrization, args.start_rates, config)
        logger.info("total log-likelihood: %s", sum(result.log_likelihoods.values()))
        samples = result.sample_reconciliations(args.samples, args.seed) if args.samples > 0 else None
        write_alerax(result, samples, args.prefix)
        logger.info("done in %.1f s", time.perf_counter() - started)
        return 0
    except (ValueError, FileNotFoundError, RuntimeError) as error:
        logger.error("%s", error)
        return 1
    finally:
        for handler in handlers:
            logger.removeHandler(handler)
            handler.close()


def entry() -> None:
    sys.exit(main(sys.argv[1:]))
```
